# Registro da 1.1.0

Execução nativa, plano em `docs/plans/v1.1-instalacao.md`.

## Decisões tomadas
- **Licença MIT.** O humano pediu "uma licença de uso" sem dizer qual, e a MIT é a permissiva mais comum para ferramenta de desenvolvedor. Custo se errado: trocar o `LICENSE` antes de publicar.
- **Troca do daemon só por versão semver mais antiga.** Uma CLI mais nova troca o daemon; uma CLI mais antiga nunca derruba um daemon mais novo.
- **Fallback por pid com confirmação.** O fallback por pid, para o daemon 1.0.0 sem a rota de encerrar, só mata o processo quando o `daemon.json` da pasta de dados confirma o mesmo pid e endereço. Um teste com servidor falso pegou a versão anterior mirando um pid qualquer.
- **PATH por usuário.** No Windows ele vai para `HKCU\Environment`, com aviso aos terminais novos (`WM_SETTINGCHANGE`). No Linux e no macOS o instalador só avisa, sem editar arquivos do shell.
- **O `atualizar` confere duas vezes.** Além do SHA256, o binário baixado precisa responder a versão da release antes de entrar no lugar.
- **Fixtures sintéticas.** As fixtures de teste copiadas do repositório privado do LyricCut viraram sintéticas, com a mesma estrutura, e os documentos ficaram sem caminhos pessoais.

## Pequenos adiados
- O PATH do Linux e do macOS não é gravado; o instalador poderia oferecer editar o `~/.profile`.
- O binário sem assinatura de código pode disparar o SmartScreen no primeiro uso.
